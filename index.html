Upload invoices by division

Drop an invoice into its division's box (the supplier PDF, or the Excel file made earlier). Check the preview, then click Save & create PIDs. Every line of that invoice gets a permanent DHH Product ID: division code + running number (MLS01, MLS02 … MLS99, MLS100). A PID is never changed or reused, even if the invoice is deleted. Uploading the same invoice again keeps its existing PIDs.

Use this data in your own website or app

Your website can also read the Firebase database directly, or use these files. Download one of these files and import it into your site's database. Download again after you add invoices here. The SQL file creates two tables, invoices and invoice_items. It works with MySQL/MariaDB and needs only small changes for PostgreSQL.

Full backup and restore

A full backup is one file with everything: invoices, PIDs and their counters, retired PIDs, purchase orders, sales documents, receipts, follow-ups, customers, users and access, company details and saved column sets. Use it to keep a safe copy, or to move the register to another database (for example the GitHub + Firebase version). Restoring only works into an empty register, so it can never overwrite data.

Clear data

Permanently removes data from the register. A full backup is downloaded first; if the download doesn't complete, nothing is deleted. Users and access are always kept, so you can't lock yourself out.

For Tally and analysis

Open All lines or Product master, choose a column set under Columns (or tick your own and save it), then use Export CSV or Export Excel. Two ready-made sets are included: “Tally – stock items” for the product master and “Analysis – purchase lines” for all lines. You can change them when you know which fields you need.
